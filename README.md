# Parole · 法语口译练习室

个人非商业学习免费的法语口译练习工具，目前提供 Apple 芯片 Mac 试用版。转写、分段和参考译文都在本机完成，无需云端 API。

> 本仓库是 Parole 的**官方发布页**。安装包与校验文件仅在 [Releases](../../releases) 中提供，请勿使用其他来源或重新打包的版本。

## 运行环境

- Apple 芯片 Mac（M 系列）
- macOS 14 或更新版本
- 建议 16 GB 内存、8 GB 可用磁盘空间
- 首次安装需联网下载运行组件和语言模型，之后可离线练习

## 下载与安装

1. 打开本仓库的 [Releases](../../releases)，在 Assets 中下载 `Parole-Mac-arm64-v0.3.7-public.zip`。
2. 解压后先读文件夹里的「先读这里.txt」，双击 `setup-local.command`，按提示完成安装。
3. 双击桌面上的 Parole 图标打开练习页；桌面没有图标时，双击安装文件夹里的 `Parole.app`。

安装包未经 Apple 公证，macOS 可能提示无法验证开发者。确认文件来自本发布页后，可参考 [Apple 的官方说明](https://support.apple.com/zh-cn/102445) 打开。

## 核验安装包

Releases 页同时提供 `SHA256-v0.3.7-public.txt`。把两个文件放在同一目录后运行：

```bash
shasum -a 256 -c SHA256-v0.3.7-public.txt
```

应显示 `Parole-Mac-arm64-v0.3.7-public.zip: OK`。官方 SHA-256 值为：

